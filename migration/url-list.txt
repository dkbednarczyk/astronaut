## Known behavior change: *.html now redirects (accepted)
# On GitHub Pages these returned 200 and served the page directly. Workers
# redirects every *.html path to its extension-less form, so they become a 307
# to the clean URL. The page still resolves, nothing is broken, and canonical
# tags already point at the clean URLs.
#
# Note /blog/two-knights.html moves from 404 to 307. That is a consequence of
# the same rule: Workers cannot 404 a .html path it always redirects.
